# HPC Security Orientation

## Mandatory Training for Sagehen HPC Users

This workshop covers security policies and best practices for the Sagehen HPC cluster at Pomona College. **Completion is mandatory within 30 days of account activation.**

## Key Information

- **Duration**: Approximately 1.5 hours
- **Requirement**: Mandatory for all new users
- **Deadline**: 30 days from account creation
- **Consequence of non-completion**: Account suspension

## What This Training Covers

- Your responsibilities as an HPC user
- Pomona's Acceptable Use Policy
- Multi-factor authentication and access security
- Data classification and handling procedures
- How to report security incidents
- Support resources and contacts

## Topics Included

1. Welcome and Responsibilities (15 min)
2. Acceptable Use Policy (20 min)
3. Authentication and Access Control (20 min)
4. Data Handling Basics (20 min)
5. Incident Reporting (15 min)
6. Getting Help (15 min)

## Prerequisites

- Active Pomona College account
- Access to email and HPC account

## How to Use This Training

1. Work through each episode in order
2. Read all material carefully
3. Complete the challenges
4. Sign or acknowledge the policy
5. Keep documentation of completion
